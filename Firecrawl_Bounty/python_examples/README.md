# Firecrawl Python SDK Examples

This repository contains practical examples of how to use the Firecrawl Python SDK for web scraping and data extraction.

## Examples Included:

1. **Basic Scrape**: A simple example to fetch the content of a URL.
   - See `basic_scrape.py`
2. **Advanced Extraction**: Demonstrates using LLM-based extraction with a custom JSON schema to get structured data from an e-commerce site.
   - See `ecommerce_extraction.py`

## Quick Start:
Install the SDK:
```bash
pip install firecrawl-python
```
Set your API Key:
```bash
export FIRECRAWL_API_KEY="your_api_key_here"
```
