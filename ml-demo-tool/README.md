# ML Demo Tool

A minimal Python package that demonstrates a simple machine‑learning model (linear regression) using scikit‑learn. It includes:

- `model.py`: defines a `LinearModel` class with `fit` and `predict` methods.
- `example.ipynb`: a Jupyter notebook showing how to train and use the model on synthetic data.

The package is ready to be published on PyPI and can be used as a quick showcase for client pitches.
