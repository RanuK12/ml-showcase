# Instant Hosting Template (Redbean)

A high-quality, single-file distributable "Status Page" template built with Redbean. Perfect for indie hackers needing a quick micro-SaaS landing or status monitor.

## 🚀 Quick Start

This project is designed to be deployable instantly.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RanuK12/redbean-landing.git
   ```

2. **Deploy:**
   Since Redbean is a single-file server, you can host the `index.html` directly on any static hosting provider (Vercel, Netlify, GitHub Pages) or run it via the Redbean server.

## 🛠 Features
- **Modern UI:** Built with Tailwind CSS and a premium dark-mode aesthetic.
- **Responsive:** Mobile-first design.
- **Interactive:** Includes a contact/notification form placeholder.
- **Lightweight:** Zero heavy dependencies, optimized for speed.
