# Redbean - Single-File Web Server Template

A professional, lightweight web server solution powered by Redbean (Lua + SQLite + TLS). Perfect for landing pages, internal tools, or quick prototypes where you need a single executable file.

## Features
- **Single File**: No complex dependencies, just run the binary.
- **Built-in SQLite**: Persistent data storage included.
- **TLS Support**: Secure connections out of the box.
- **Lua Scripting**: Easily customize behavior with Lua.

## Quick Start
1. Download the `redbean` binary.
2. Run `./redbean -p 8080`.
3. Access your site at `http://localhost:8080`.
