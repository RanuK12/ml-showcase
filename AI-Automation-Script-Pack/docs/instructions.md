## 🔧 Requisitos

- **Python 3.8+** instalado.
- Acceso a terminal/command line.
- Librerías comunes (se instalan automáticamente al ejecutar los scripts).
- Para algunos scripts: Chrome (WhatsApp Web), yt-dlp, etc.

---

## 📜 Descripción de cada Script

| Script | Descripción | Uso |
|--------|-------------|-----|
| `clean_downloads_folder.py` | Organiza archivos en ~/Downloads por tipo y fecha. | `python3 clean_downloads_folder.py` |
| `automate_github_backup.py` | Backup automático de repositorios locales en ~/GitHub. | `python3 automate_github_backup.py` |
| `auto_whatsapp_web_sender.py` | Envía mensajes por WhatsApp Web usando Selenium. | `python3 auto_whatsapp_web_sender.py "+54935..." "Hola"` |
| `auto_youtube_downloader.py` | Descarga videos de YouTube a alta calidad. | `python3 auto_youtube_downloader.py <URL>` |
| `auto_google_photos_backup.py` | Backup automático de fotos desde Google Photos. | `python3 auto_google_photos_backup.py` |
| `auto_telegram_backup.py` | Backup de chats de Telegram. | `python3 auto_telegram_backup.py` |
| `auto_rename_photos_by_date.py` | Renombra fotos por fecha de creación. | `python3 auto_rename_photos_by_date.py` |
| `auto_excel_to_pdf.py` | Convierte archivos Excel a PDF. | `python3 auto_excel_to_pdf.py archivo.xlsx` |
| `auto_rename_downloads_pattern.py` | Renombra archivos en ~/Downloads por patrón. | `python3 auto_rename_downloads_pattern.py` |
| `auto_twitter_scraper.py` | Extrae tweets de un perfil de Twitter. | `python3 auto_twitter_scraper.py @usuario` |

## 🚀 Cómo Empezar

1. **Descarga el pack** desde Gumroad.
2. **Descomprime** el archivo ZIP.
3. **Abre una terminal** en la carpeta `AI-Automation-Script-Pack`.
4. **Ejecuta** el script que necesites usando Python:
   ```bash
   python3 scripts/nombre_del_script.py
   ```
5. **Sigue las instrucciones** en pantalla.
