# AI Prompt Helper

A tiny utility for generating and refining prompts for LLMs. Built with Python, it lets you:
- Craft prompts with placeholders.
- Apply context-aware refinements.
- Export ready‑to‑use prompts for OpenAI, Groq, Mistral, etc.

## Why?
Emilio often needs quick, well‑structured prompts for his outreach, bounty fixes, or internal tools. This repo gives a ready‑made, reusable piece of code he can showcase on his portfolio and use in day‑to‑day work.

## Install
```bash
pip install -r requirements.txt
```

## Usage
```bash
python prompt_helper.py "Create a LinkedIn post about a new AI tool" --style professional
```
